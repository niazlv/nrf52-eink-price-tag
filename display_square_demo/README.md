# SSD1675A Mandelbrot demo

Минимальный проект для статьи: только драйвер дисплея, простая графическая библиотека и `main.c`, который рисует фрактал Мандельброта в трех цветах: черный, красный и белый.

Состав:

- `src/lib/graphics.*` - буфер, поворот, пиксели, прямоугольники, текст.
- `src/lib/mandelbrot.*` - пример отрисовки фрактала поверх графической библиотеки.
- `src/drivers/ssd1675a.*` - драйвер e-paper контроллера.
- `src/drivers/soft_spi.*` - программный 9-bit SPI.
- `src/main.c` - минимальная инициализация и вывод готового буфера на экран.

Пины сейчас такие же, как в исходном проекте:

- `BUSY = 6`
- `RST = 7`
- `CS = 8`
- `CLK = 11`
- `MOSI = 12`
- `VCC = 19`

Пример сборки:

```sh
west build -b nrf54l15dk/nrf54l15/cpuapp display_square_demo
```

Или из этой папки:

```sh
make build
```

Если используешь другую плату, поменяй board target и при необходимости пины в `src/drivers/ssd1675a.h` и `src/drivers/soft_spi.h`.
