Li-Po 3.7V/350mAh. АЦП видит до 3.6V (насыщение) — заряд отслеживается только при разряде. Ток рассчитывается прошивкой. Ниже 3.3V экран блокируется, ниже 3.1V — глубокий сон.
Имя ценника
Сейчас—
К имени всегда добавляется неизменяемый «(XXXXXX)» — уникальный код устройства; по нему ценник находится в списке даже после переименования. До 16 символов, сохраняется в ценнике.
Mesh-приём энергосбережение
Сейчас—
Приём широковещательных команд от соседних ценников (BCAST). Выключение экономит ~0.2–0.3 мА — батарея живёт в разы дольше, но ценник перестаёт слышать и ретранслировать mesh-команды: включить обратно можно только здесь, по прямому подключению. Нужна прошивка v3.4.1+.

NFC-метка быстрое подключение
Зашивает в метку ссылку на это приложение с именем подключённого ценника (имя + код = ровно один ценник в списке) и, по желанию, паролем. Тап телефоном по метке → открывается приложение, остаётся нажать «Подключить». Запись — только Chrome на Android, открытие работает и на iPhone.
